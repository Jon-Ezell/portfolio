# LymeLess case study — design

**Source:** Jon's LymeLess write-up (`fdf.docx`, ~4,500 words, 36 images).
**Route:** `/lymeless`

## Intent
Add LymeLess as a polished case study that matches the structure and length of ALTR / Deep Journey (~1,500 visible words). Lead with the strongest points and key results/learnings. Lose no context: the rest of the doc lives in collapsed "go deeper" panels.

## Approaches considered
- **A. One page + collapsible "go deeper" panels per section (chosen).** One URL; skimmers never see the depth; follows Deep Journey's existing "Nitty Gritty" expander.
- B. Main page + separate `/lymeless/notes` appendix. Cleaner, but two pages to maintain and the reader leaves the story.
- C. A + a single screen gallery. Screens would lose the captions that carry much of the story.

## Structure (mirrors Deep Journey)
Hero + project details + 4 stats → TL;DR (problem / solution / results) → sticky local nav (the index) → Background (two cliffs) → Research (3 rounds, breadth table visible) → Strategy (hypothesis, metric, sequencing) → Solution (onboarding, IA re-rack, activation) → North Star → Impact + key learnings → Footer CTA.

Each section shows its strongest point + 1–2 images; a "Go deeper" panel holds the remaining text and screens, with every image opening full size in a new tab.
